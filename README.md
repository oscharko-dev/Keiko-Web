# Keiko Landing Page

This landing page is fully standalone and has no external dependencies.

## Run locally

```bash
npm install
npm run dev
```

Vite starts the site at `http://127.0.0.1:4173` with instant hot module replacement for HTML,
CSS, and JavaScript changes.

## Create a production build

```bash
npm run build
```

The generated static files are written to `dist/`.
